# Claude Code project starter

Este pacote contém:
- `CLAUDE.md`: instruções persistentes para Claude Code.
- `SPEC.md`: especificação funcional e técnica inicial.
- `.claude/skills/`: skills locais do projeto para tarefas recorrentes.

## Como usar
1. Copie os arquivos para a raiz do repositório do jogo.
2. Mantenha `.claude/skills/` no controle de versão se quiser compartilhar essas skills com o projeto.
3. Revise `SPEC.md`, especialmente as regras marcadas como provisórias ou em aberto.
4. Não conecte MCPs nem instale skills de terceiros sem revisar permissões e conteúdo.

As skills são instruções de fluxo de trabalho; não adicionam dependências Java à aplicação.
