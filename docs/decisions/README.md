# Registro de decisões

Cada decisão relevante (arquitetura, ferramentas, regras centrais com impacto
no futuro) ganha um arquivo `NNNN-titulo-curto.md` com: contexto, opções
consideradas, decisão e consequências.

- Status possíveis: **Proposta**, **Aceita**, **Substituída por NNNN**.
- Uma decisão aceita não é editada para mudar de ideia: cria-se uma nova
  que a substitui.
- Regras de jogo (pontuação, moral, copas etc.) ficam na `SPEC.md`. Aqui
  ficam as decisões de *como* construir e as escolhas entre alternativas.
